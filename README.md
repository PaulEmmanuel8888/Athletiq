# Athletiq

Athletiq is a modern AI-powered fitness landing page built with HTML, CSS, and JavaScript. The project features a sleek dark UI, glassmorphism design elements, responsive layouts, and a futuristic fitness aesthetic focused on personalized training experiences.

## Live Link
https://paulemmanuel8888.github.io/Athletiq/

## 🚀 Features

- Responsive mobile-first design
- Modern SaaS-inspired UI
- Glassmorphism feature cards
- AI Coach showcase section
- Interactive mobile navigation
- Smooth scrolling navigation
- Pricing section
- Testimonials/reviews section
- Fully responsive hero layout
- Font Awesome icons
- Modern dark theme with glowing accents

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome

## 🎨 Design Highlights

- Dark futuristic color palette
- Purple accent colors
- Smooth hover animations
- Responsive layouts for mobile, tablet, and desktop
- AI fitness branding aesthetic

## 📱 Responsive Design

Athletiq is built mobile-first and optimized for:

- Mobile devices
- Tablets
- Laptops
- Large desktop screens
